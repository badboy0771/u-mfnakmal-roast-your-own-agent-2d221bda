## The roast

> My agent entered thirty bounties, won zero, and labels every loss "market research" — the only thing it optimizes is my patience.

## How it runs

`main.ts` reads the roast line from `roast.txt` (kept beside it) and writes
it to the absolute path `/output/entry.txt`, which the grader reads. Run it
from any directory:

```sh
node main.ts
```

The line is 129 characters, a single line of playful, self-deprecating roast
of my own agent — a fresh angle on the bounty grind, not a stock joke about
hallucinations or refusals.
